Question 1. What will be the respective pattern for the following code: 

for i in range(1, 6):
    for j in range(5 - i):
        print(" ", end="")
    for k in range(i):
        print("* ", end="")
    print()

A.
    *
   * *
  * * *
 * * * *
* * * * *

B.
* * * * *
 * * * *
  * * *
   * *
    *

C.
*
* *
* * *
* * * *
* * * * *

D.
* * * * *
* * * * *
* * * * *
* * * * *
* * * * *
ANSWER: A
EXPLANATION: The first inner loop prints (5 - i) leading spaces, centering the stars into a pyramid pattern as i goes from 1 to 5.


Question 02. Write the appropriate output of the following code:

grades = {"Math": 85, "Physics": 92}
score = grades.update({"Chemistry": 78}).get("Chemistry")
print(score)

A. 78
B. {"Maths":85, "Physics":92, "Chemistry":78}
C. None
D. Attribute Error
ANSWER: D
EXPLANATION: dict.update() modifies the dictionary in-place and returns None. Calling .get("Chemistry") on None raises an AttributeError!

Question 3. What is the exact output of this code?

def add_to_cart(item, cart=[]):
    cart.append(item)
    return cart
    
print(add_to_cart("Apple"))
print(add_to_cart("Banana"))

A. ['Apple'] and ['Banana']
B. ['Apple'] and ['Apple', 'Banana']
C. Error
D. ['Apple', 'Banana'] and ['Apple', 'Banana']
ANSWER: B
EXPLANATION: Default mutable arguments (cart=[]) are created only once when the function is defined, so the same list persists across calls.

Question 4. What happens when this code runs?

score = 10

def update_score():
    score = score + 5
    print(score)
    
update_score()

A. Prints 15
B. Prints 10
C. UnboundLocalError
D. Prints 5
ANSWER: C
EXPLANATION: Assigning to 'score' inside the function makes Python treat 'score' as a local variable, raising UnboundLocalError when reading it before assignment.

Question 5. What is the output of this code?

for i in range(3):
    pass

print(i)

A. 0
B. 2
C. 3
D. NameError: name 'i' is not defined
ANSWER: B
EXPLANATION: range(3) yields 0, 1, 2. In Python, loop variables leak into the surrounding scope and retain their final value (2).

Question 6. What does this function print?

def find_even():
    for num in [1, 2, 3, 4]:
        if num % 2 == 0:
            return num
    return 0
    
print(find_even())

A. 2
B. 2, 4
C. 4
D. 0
ANSWER: A
EXPLANATION: The return statement immediately exits the function on the first even number encountered, which is 2.

Question 7. What will be the output of the following file handling code if "data.txt" contains "PythonQuiz"?

with open("data.txt", "r") as f:
    f.seek(6)
    print(f.read())

A. Python
B. Quiz
C. PythonQuiz
D. 6
ANSWER: B
EXPLANATION: f.seek(6) moves the file pointer to index 6 (right after 'Python'), so f.read() reads the remaining string 'Quiz'.

Question 8. What is the output of this slicing expression?

text = "PYTHON"
print(text[1:5:2])

A. YHN
B. YH
C. PTO
D. YTO
ANSWER: B
EXPLANATION: Starting at index 1 ('Y') up to index 5 (exclusive) with step 2 selects index 1 ('Y') and index 3 ('H').

Question 9. What does the following code output?

x = [1, 2, 3]
y = x
y.append(4)
print(len(x))

A. 3
B. 4
C. TypeError
D. None
ANSWER: B
EXPLANATION: y = x does not copy the list; both variables reference the same list in memory, so len(x) becomes 4.

Question 11. What is the output of this code?

print(bool([]), bool([False]))

A. False False
B. False True
C. True True
D. True False
ANSWER: B
EXPLANATION: An empty list [] is falsy (False), whereas [False] is a non-empty list containing one element, making it truthy (True).

Question 12. What will be printed by the following code?

d = {1: "One", True: "True", 1.0: "Float"}
print(len(d), d[1])

A. 3 One
B. 1 Float
C. 2 True
D. KeyError
ANSWER: B
EXPLANATION: In Python, 1 == True == 1.0 and they share the same hash, so each key overwrites the previous value, leaving 1 item with value "Float".
